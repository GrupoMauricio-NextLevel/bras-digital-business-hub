# NextLevel v2 — kit completo de identidade e implementação

Marca-mãe aprovada: **NextLevel / SOLUÇÕES DIGITAIS**. Direção: NL Orbital + Orbital em Avanço + Prisma Digital integral.

## Início rápido

1. Extraia os ZIPs recebidos na mesma pasta, preservando a raiz `nextlevel/`.
2. Envie `COMECE-AQUI-CLAUDE.md` ou o conteúdo de `docs/PROMPT-ENGENHEIRO-MESTRE-CLAUDE-CODE.md` ao Claude Code.
3. Peça aplicação no site institucional e no Master existentes.
4. Confira `docs/INVENTARIO.md` para arquivos, dimensões, alpha e tamanhos reais.

## Regras essenciais

- `clara` significa asset para superfície clara, com lettering marinho; `escura` significa asset para superfície dark, com lettering claro.
- Logos e monogramas de produção têm alpha real. O fundo das prévias não está embutido nessas versões.
- O acabamento prisma já faz parte do PNG. Não aplicar filtros, recoloração ou sombras extras.
- A versão flat é uma adaptação óptica para pequenos componentes; mantém a mesma identidade.
- Preserve o arquivo de referência aprovado para conferir qualquer futura exportação.
- O tema do Master não deve substituir as marcas-filhas.
- Os arquivos são PNGs raster. Não há vetor editável ou fonte instalável. Para produção gráfica que exija vetor, reconstruir cuidadosamente a geometria a partir da referência; o acabamento prismático continua como imagem.
- Os ZIPs finais ficam abaixo de 30.000.000 bytes por arquivo, com inventário verificável.
