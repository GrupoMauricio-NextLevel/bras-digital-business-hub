# Brás Digital Club — Fase E8b: benefícios cruzados do grupo (D121)

## Em 4 linhas (para o dono)
- **Fardo entregue pela Starline vira pontos** para o cliente (100 pontos = R$ 1,00 por fardo), pagos pela Starline. Usados na Mega Tron, entram no acerto do mês.
- **O plano da Brás sobe o nível no Club:** Platinum é VIP; Ouro é Frequente.
- **Guia de excursão:** no balcão, o atendente informa o cartão do guia que trouxe o passageiro. O guia ganha 2% da compra em pontos.
- Todos os valores ficam no Master → Brás → Club → Regras → "Benefícios cruzados do grupo".

## O que depende de você
1. Confirmar 100 pontos por fardo e 2% para o guia.
2. Quem paga o desconto se o cliente usar pontos no frete de um ônibus de fora do grupo (para ligar pontos no Pix do frete).
3. O sistema emissor do Nota Fácil (para integrar a emissão).
