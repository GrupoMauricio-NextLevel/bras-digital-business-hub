Registrar a decisão **não liga nada**: só guarda a escolha, com data, na auditoria. Para ligar de fato, use o botão "Onde ligar" do item ou a chave indicada no Render.

Repetir no começo de cada mês. Quando o mês vira, todo item desligado volta a aparecer como "Sem decisão este mês".
